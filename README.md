# Apriori Algorithm

A Python project for finding frequent itemsets and association rules using the Apriori algorithm.

## Overview

The project analyzes transaction data stored in an Excel file to discover items that frequently appear together.

## Features

- Read transaction data from an Excel file.
- Generate frequent itemsets (L1, L2, ..., Lk).
- Calculate support.
- Generate association rules.
- Calculate confidence and lift.
- Visualize results using charts.
- Test different minimum support and confidence values.

## Requirements

- Python 3
- pandas
- openpyxl
- matplotlib

## Installation

Install the required libraries:

```bash
pip install pandas openpyxl matplotlib
```

## Usage

Run the main Python script:

```bash
python main.py
```
